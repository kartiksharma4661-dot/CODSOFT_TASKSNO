CODSOFT TASK 1 — PERSONAL PORTFOLIO
====================================

Files:
- index.html : website structure
- style.css  : white-and-blue styling and mobile responsive layout
- script.js  : mobile navigation and footer year

HOW TO OPEN:
1. Extract this ZIP into a folder named CODSOFT_TASK1.
2. Open index.html in a browser, or open the folder in Acode.
3. Keep all three files in the same folder.

BEFORE SUBMISSION:
1. Replace YOUR_EMAIL@example.com in index.html with your real email.
2. Add your own resume PDF in this folder and name it Kartik_Sharma_Resume.pdf.
3. Update the project cards to accurately describe your real work.
4. Check the website on mobile and test every navigation link.
5. Upload the folder to a GitHub repository named CODSOFT_TASK1.
6. Record a short demo video and share it on LinkedIn as requested in the CodSoft task PDF.

Note: The portfolio uses initials "KS" instead of a personal photo. You can replace it with your own photo if you want.
